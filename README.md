# AI Cover-Letter Generator 🤖✉️

Веб-инструмент: вставляешь **вакансию** и **резюме** → бесплатная нейросеть пишет
**сопроводительное письмо** под эту вакансию (EN/RU), подсвечивает совпадающие навыки,
при желании вставляет слово-маркер и **не выдумывает** фактов сверх резюме.

**Стек:** Python · FastAPI · LLM (Groq, провайдеро-независимо) · vanilla JS.

## Запуск локально
1. Возьми бесплатный ключ Groq на **console.groq.com** (без карты).
2. `copy .env.example .env` и впиши `GROQ_API_KEY`.
3. ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   uvicorn app:app --reload
   ```
4. Открой http://127.0.0.1:8000

## Как устроено
- `app.py` — FastAPI: `GET /` отдаёт страницу, `POST /api/generate` вызывает LLM и
  возвращает `{letter, match_summary}` строгим JSON.
- `llm.py` — провайдеро-независимый клиент (Groq по умолчанию, модель меняется одной
  переменной `LLM_MODEL`).
- `static/index.html` — интерфейс (две области ввода, язык, слово-маркер, копирование).

## Деплой
Есть `Dockerfile` — разворачивается на любом контейнерном хостинге (напр. Amvera):
`GROQ_API_KEY` задаётся переменной окружения, порт 8000.
